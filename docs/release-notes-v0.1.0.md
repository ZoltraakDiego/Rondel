# Rondel · 回环诗 0.1.0

Rondel 的首个公开版本，从渐进相识与研究画像出发，接续阅读、可信准备、有限实验与归因，再将关键数据和候选 claim 整理成论文与研究交付。研究者参与核心问题、结果解释和路径取舍，Agent 协助重复工作、来源核验、代码与持续记录。

本版通过 `rondel-main` 提供 Main 7、Pre 6、Mid 8、Post 7，共 28 个研究工作流，以及七个本地辅助脚本。支持冻结设置与变更影响追踪、实际运行与分析分离、任务相关上下文、阶段沉淀、Markdown/Obsidian 视图及按明确文件清单生成复现包和资料包。主页面加入“回环中的火种”标志、深浅页眉和中英文介绍。

下载 `rondel-main-0.1.0.zip` 后，保留解压得到的完整技能目录，按主页中的 Codex 或 Claude Code 说明接入。`rondel-main-0.1.0.manifest.json` 提供包内逐文件摘要，`SHA256SUMS.txt` 用于核对下载文件。辅助脚本需要 Python 3.11+ 与 PyYAML，源码和原创视觉素材采用 MIT 许可。

完整回归已有 173 项通过，另已核对技能格式、共享资源、独立安装与交付导出。工程检查覆盖文件、记录和状态等能力，科学判断、生成式交互和实际宿主操作继续按真实研究材料审阅。实际执行使用当前宿主工具与明确范围，研究档案保存在用户工作区 `.rondal/`，私人来源记录和测试档案不包含在发布包内。
