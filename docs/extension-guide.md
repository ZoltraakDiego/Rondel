# 扩展说明

新增任务先明确它服务的问题、最小输入、产物、所需上下文和状态变化，再在工具目录登记。已有 planned 工具逐项进入 available 时，提供真正可用的入口、任务说明和验证案例。main 的路由只加载目标集合，不预读所有流程。

共享记录合同按 schema_version 维护，字段变化需要兼容说明和旧记录保留策略。对阶段、主线与 claim 等需要人的边，记录真实来源；事实核验与科学采纳继续分开。新增脚本仅在重复且确定性的操作有实际收益时加入。

每个安装目录包含自身所需的共享规范、模板和辅助脚本。根目录 shared 是维护源，由 build_skills 同步到安装目录，检查模式可发现二者漂移。外部论文工具、远程环境或笔记系统按任务适配，核心不依赖某个私人路径或特定连接器。
