# Rondel 的视觉标志

标志名为“回环中的火种”：松绿色墨线回旋向内，开口处留一粒暖金色火种。回环呼应带着新证据重访最初问题，火种承接 Init 中“在黑暗中播撒火种”的意象。它表达研究过程中的连续性与尚未封闭的可能，配合纸色背景和衬线字标形成安静的阅读感。

主色为松绿 `#214E46`，纸色 `#F7F4EB`，强调色为暖金 `#C38B42`。深色页眉使用墨绿底、浅纸色线条与较亮的暖金，明暗版本保持相同图形。不要靠修改图形或增加复杂阴影来表达版本、状态或阶段。

源文件见 [标志 SVG](assets/rondel-mark.svg)、[浅色页眉](assets/rondel-hero-light.svg)和[深色页眉](assets/rondel-hero-dark.svg)，均为本项目绘制的可编辑矢量图形，沿仓库 MIT 许可发布。PNG 版本用于头像与分享，使用时保留周围留白，不拉伸图形比例。主页使用 GitHub 支持的图片与 HTML 标记，显示规则以 [GitHub Flavored Markdown](https://github.github.com/gfm/) 为准。
