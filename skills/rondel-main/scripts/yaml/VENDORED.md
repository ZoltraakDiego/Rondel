# PyYAML 6.0.3

This directory contains the complete pure-Python `yaml` modules from the PyYAML 6.0.3 distribution, with the upstream MIT license in LICENSE. The optional compiled LibYAML extension is not bundled; PyYAML's upstream Python fallback is used when it is unavailable. Modules are preserved without local behavioral changes.

Source: https://github.com/yaml/pyyaml/tree/6.0.3/lib/yaml
Distribution: https://pypi.org/project/PyYAML/6.0.3/

Bundling lets the installed Rondel command-line helpers run with a valid Python interpreter even when the host has no third-party site packages. Development dependencies remain declared in the repository's pyproject.toml.
