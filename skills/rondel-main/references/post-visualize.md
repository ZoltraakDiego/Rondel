# post.visualize：用图表表达一项有证据的认识

先明确图要回答的问题、支持的主张、读者应看到的比较和真实数据来源，再选图形与布局。读取项目已有视觉规范和产物位置，定量结果使用当前可用的标准绘图工具，保留源数据、处理代码和导出文件。当前工程架构与工作流优先 Mermaid，用户明确选择其他格式时沿其要求。

记录取样范围、过滤、聚合单位、归一化、误差或不确定性与参数，完整覆盖和展示子集分别描述。降维或热图说明拟合数据、变换、颜色和随机性，不能通过视觉筛选后继续宣称全量统计。对照结果、轴和单位、背景处理及统计口径与稿件保持一致，不补造数据。

purpose: figure_plan 使用 [图表模板](../assets/templates/figure-plan.md)，关联 claim、有效数据与具体产物。导出后在实际展示尺寸核对字体、裁剪、标注、图例、颜色和信息层次，检查是否清楚表达本轮结论。AI 生成的概念图或占位示意按实际来源标注草稿性质，定量图只用真实数据，不将样例图当成实验结果。

交给 post.write 的是可编辑图、发表所需格式、图注与数据入口，仍缺内容进入图表任务。生成媒体与软件选择使用当前宿主实际能力，工具不可用时保留源数据与可执行方案，不声称已渲染或已导出。研究者主要判断图是否准确表达中心认识与比较。
