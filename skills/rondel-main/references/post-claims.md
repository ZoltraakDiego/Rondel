# post.claims：组织主张、证据与方法边界

将稿件或口述中的候选认识拆成可核对的陈述，分别定位性能、机制、归因、成本或适用性证据。每条说明条件、覆盖、来源和未解决的替代解释，数字与版本回到原始产物。真实改进、有价值的负面发现和仅有工程观察各按实际范围组织。

创建或更新 claim，candidate、evidence_linked、reviewed、adopted 等沿正常状态与用户来源保存；正式采用或撤回由真实决定形成。新证据影响已采用主张时进入 needs_review，补对应依据再审阅。引用存在只说明可追溯，支撑程度仍要读取与解释，不能把记录关联当成自动科学证明。

purpose: claim_evidence 使用 [主张证据模板](../assets/templates/claim-evidence.md)，将主张映射到实际运行、分析、原文、推导和图表。局限从方法条件、依赖、失效行为和代价说明，随机种子与版本等工程说明放到复现位置，只有确实影响方法解释时才进入相应讨论。缺口说明是缩小主张、补关键证据、暂存还是撤回，避免反复追加不服务中心问题的实验。

交给 post.visualize/write 的是当前可表达主张、适用条件和精确来源，仍是候选的部分明确作为待研究内容。研究者参与中心句和取舍，AI 提供表述与对应依据。主线或贡献重心变化按实际选择更新，旧认识原样保留。
