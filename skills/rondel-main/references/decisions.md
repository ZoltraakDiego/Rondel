# 人的决定

决定记录包含用户实际表达的选择、来源、适用对象、范围及理由。明确的“可以做上述几组”“先停止这条分支”“开始收敛”可以直接记录，无需再次询问同一选择。AI 建议、假设评估和人的采纳分别保存。

`source` 使用 kind、reference、quote，分别记录当前用户消息或明确用户笔记、可定位来源和必要原话。历史自动跟进内容和模型转述不标为人的新决定。恢复已有任务时核对原范围、当前指令和实际状态，保留仍有效的具体决定。

项目阶段、主线确认、优先问题、假设选择和正式 claim 采纳需要人的明确来源。客观材料核验和候选解释可以由 AI 记录，并标明证据状态。脚本检查来源字段完整性；调用者负责忠实于真实交流，字段本身不构成执行授权。

讨论后的决定保存独立笔记，相关对象状态通过显式操作更新。一个决定可以覆盖有限清单，避免逐个机械确认；超出范围时回到新的研究选择。修订时引用前一决定并解释改变，旧记录留在历史中。
