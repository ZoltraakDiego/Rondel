# mid.analyze：把有效结果变成可继续的认识

先读有效运行、实际条件、预期与否证约定和原始结果，按条件、操作、观察与判断给一个完整结论段落。总体指标、逐条件收益与损伤、关键错误行为、资源代价和不一致证据一起解释。数字回到实际产物，来自工程检查、冻结表征诊断和完整训练的证据分别注明范围。

检查收益是否可由容量、训练量、输入、监督、融合接口或评价差异解释，依据现有对照提出支持、削弱或仍未区分的机制判断。按实际独立单位汇总，视频、主体、任务、折或种子与相关帧不能混作独立重复；效应、不确定性和统计方法有实际依据再报告。测试或模型选择边界保持冻结，不为了得到正结果不断追加搜索。

使用 [实验分析](../assets/templates/experiment-analysis.md) 保存 purpose: experiment_analysis，关联 run_inspection、有效 run、hypothesis 和 setting_refs。假设评估 assessment 和用户是否继续是不同对象：证据可标 supported、weakened 或 unresolved，实际路径选择另有决定。请研究者解释一次最关键的行为变化或保留意见，AI 整理对照和来源。

一轮结束给出能改变下一项判断的推荐，范围明确地继续、修正、暂存或进入收敛。负面结果说明具体条件、未能解决的行为、仍可用的证据和剩余问题，不用单个头或种子替代整个架构结论。需要扩大范围时形成新的有限方案，足以收拢时按 [中期收束](mid-cycle.md) 交给 Main。

将关键实验数据、条件、来源与候选 claim 关联保存，实验期按当前任务记录认识即可。最后进入论文组织时，Post 对研究笔记统一审阅并决定材料去向，流程见 [笔记到论文取舍](paper-material-selection.md)。候选 claim 的数量不等于论文贡献数量，后续合并、缩小或暂存都保留理由与原证据。
