# 问答结束：整体理解、推荐计划与 Main 交接

问答足以支持一个有意义的起点时，主动收束。交付顺序是一个完整的用户理解段落、一份推荐计划与排期，以及围绕关键差异的共同修订。展示这些内容后再保存，接续已认可的第一项工作；用户无需从零回答“接下来做什么”。

## 一个段落表达对用户的理解

用一个完整自然段、通常三至五句，直接对用户说“我目前对你的理解是……”。串起已有经历、当前目标与动机、技术想法所处阶段、现实约束，以及希望怎样合作，让读者看见这些信息之间的联系。写具体的经验与选择，用户尚未决定的部分自然留白，候选设想按假设或倾向表达。

这一段应有判断与关联，例如“已有实现经验，但新设定尚未复现，因此希望先找到可靠起点”；不需要复述每轮问答、罗列画像字段或替用户贴性格标签。已有明确回答直接采用，只有 AI 的概括或尚不清楚的取舍才邀请修正。访谈过程中先自然接话，避免每轮都机械复述“我已经记下”。

收束前将领域凝练为一句适合检索的摘要，保留研究对象、关键设定和用户实际采用的常用别名，例如“少样本细粒度的视觉异常检测（VAD/IAD）”。在整体理解段落中自然说出“你的当前方向可以先凝练为……”，再承接动机、经历与约束，让用户能够修订这句话。它负责定位领域，具体痛点、研究问题、技术候选和论文贡献各自按证据维护。

用户认可后保存 `research_anchor.search_summary`，configure 自动同步画像 `collaboration.profile.research_domain` 的 summary 与 source。画像也可作为入口更新这一项，但两处同时提交时必须一致，其他有效偏好保留。旧档案缺少摘要时正常恢复，在相关讨论中补齐，不重做访谈。

## 主动给出一份推荐计划与排期

理解段落之后直接提出推荐方案，说明为什么这样的顺序适合用户的起点、目标和投入。计划覆盖从当前状态走向近期成果的主要阶段，并明确当前优先项；后续阶段可以随证据细化。研究尚无方向时，计划本身可以围绕澄清问题与筛选路径展开。

排期可用一张紧凑表格，列出阶段、建议时间窗口、具体产出，以及该阶段结束时要判断什么。日期已明确时结合里程碑倒排，投入或资源未知时用可修订的周次、工作时段或讨论次数，并说明估计依据。实验、资源核验、分析、写作与缓冲按本次目标分配，不能把“有效时间有限”当成全职投入，也不把研究结果写成按日期必然交付的承诺。

技术设想涉及模型或模块时，起步阶段优先核对最接近的成熟论文与真实实现。每个阶段都应带来能够影响下一步的认识，例如是否已找到可比基线、哪项对照能检验核心假设、现有证据能否支持主张。资源、协议和具体运行范围在对应任务中核实，阶段计划只负责说明要走到哪里、何时一起看什么。

只有足以影响整个计划的缺口才继续追问。其余不确定条件写成计划假设或待核对项，让用户能够先评价一个具体方案。可参考 [计划模板](../assets/templates/research-plan.md)，按真实问题改写，而非强制采用固定阶段数。

## 一起打磨后再保存

先展示整体理解和完整计划，再邀请用户优先调整目标、节奏、阶段安排或第一步中最重要的一处。用户直接表示“就按这个开始”时记录其采纳范围；只修正一部分时更新相关内容，并保持其他已有明确选择。随后根据实际来源保存当前版本，存储位置未确定时再询问工作区。

用户指定的是工作区，Rondel 的记录与更新全部进入 `<工作区>/.rondal/`。理解段落与计划摘要写入 `.rondal/init.md`，完整计划按需要保存为 `discussion` 记录并带上 `purpose: research_plan`；认可与关键修正通过决定记录关联。未被采纳的推荐计划仍是建议稿，可以先保存为可审阅版本。

`next_step` 保存当前任务名称、对应 `plan_ref`、用户选择的来源或决定引用，以及预期产出。用户认可了理解与适用计划，且第一步明确、保存位置已确定时，才将 Init 标为 ready，并按实际工作选择 `ready_for` 与 `phase`。保存正文使用 `configure` 的可选 `body`，重读并保留其他有效内容与历史版本，操作见 [辅助脚本](helper.md)。

## Main 从当前计划接续

Main 接收已认可的研究起点、当前计划引用、第一项任务、复盘节奏及仍开放的条件。下一轮先定位计划中的当前位置，结合实际产物继续该任务，或在任务结束时进行约定的复盘。用户说“接下来是什么”时，回答当前阶段、最近产出与推荐下一项；用户已经选择继续时在既有范围内推进。

计划是随认识更新的协作依据。结果、资源或目标变化时，说明它影响哪一段安排，保留原计划，再共同调整必要部分。具体循环见 [Main 链路](main-cycle.md)，恢复过程沿用 [按需加载](shared/context-loading.md) 与已有决定来源。
