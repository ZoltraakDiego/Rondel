# post.converge：收拢到一个可解释的当前版本

读取有效分析、候选方案、问题优先级和实际决定，对照相同数据与协议审阅收益、损伤、代价和机制证据。推荐保留哪些部分及其作用，哪些旁支暂存，以及当前版本能够回答什么。基于验证和既定选择规则收拢，不用反复查看测试结果挑选配置。

区分已经实现、实际训练、冻结诊断与尚未验证的设想，清楚描述当前架构或负面发现。若中心证据不足，给出有限关键补充，说明完成后如何返回收敛；外围探索进入带入项或归档。让研究者用自己的话解释当前中心认识，Agent 整理版本、证据和候选取舍。

接续实验期的关键数据和候选 claim，按 [论文材料取舍](paper-material-selection.md) 对当前项目笔记做有覆盖记录的统一审阅，再决定主文、补充、研究档案与待核验内容。通过 purpose: paper_material_selection 的 discussion 保存材料位置、审阅状态、取舍理由与推荐故事线，分批展开原文控制上下文。已有用户解释直接使用，不要求其重新口述每份笔记；新问题只聚焦影响中心判断的一处。

purpose: convergence 使用 [收敛模板](../assets/templates/convergence.md)，关联保留版本、设置引用、有效结果、代价、暂存理由与补充清单。用户实际选择后更新当前计划和需要变更的对象状态，已批准方案与历史运行原样保留。向 post.mechanisms/claims 返回可审阅的问题—想法—证据主线，并向 Main 返回是否具备写作条件。
