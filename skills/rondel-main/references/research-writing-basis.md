# 研究组织与写作：采用哪些依据

本指引区分当前用户要求、历史研究记录、外部作者的经验与本技能的实现选择。当前明确修正优先于旧笔记里的计划，笔记中的 Agent 总结和历史实验值不自动成为用户已确认观点或当前科学事实。这里只吸收会改变组织、核验和表达的具体做法，实际稿件仍使用当前材料与目标要求。

| 来源与核对时间 | 支持的具体做法 | 本技能的采用范围 |
|---|---|---|
| 用户当前对话，2026-10-27 | 先记录关键实验数据和候选 claim，最后统一审阅笔记、决定论文取舍；收尾准备复现包、资料包与告别 | [材料取舍](paper-material-selection.md)、[研究收尾](post-closeout.md) 的默认路线 |
| 历史协作 H06 / H07 与匿名笔记依据 N01–N04 | 中心句与章节连贯、经典术语、条件明确的结论、必要的主文与补充取舍；来源和版本对应 | 接续已有解释，整理实际发现；历史固定图数、数据集或页数不作通用门槛 |
| Simon Peyton Jones，[写作讲义](https://www.microsoft.com/en-us/research/wp-content/uploads/2016/07/How-to-write-a-great-research-paper.pdf)，2026-10-27 读取 | 凝练核心想法、说明问题与价值、可检验贡献对应正文证据 | 中心发现段落、章节连接与主张核对；其建议中提前写作的做法本轮不设为默认 |
| Neel Nanda，[Explore, Understand, Distill](https://forum.effectivealtruism.org/posts/hmBPqApDXvhLzbiFt/how-i-think-about-my-research-process-explore-understand)，2026-10-27 读取作者正文 | 区分获取认识、检验假设、压缩和交流成果，允许根据认识回到先前工作 | 阶段目标和有限补充；这是作者经验，不能代替当前证据与用户取舍 |
| Andrej Karpathy，[A Recipe for Training Neural Networks](https://karpathy.github.io/2019/04/25/recipe/)，2026-10-27 读取 | 检查数据、建立可信管线、逐步增加可检验复杂度 | 与来源保真和有限实验配合，工程检查与研究机制证据分别报告 |
| NeurIPS，[Paper Checklist](https://neurips.cc/public/guides/PaperChecklist)，2026-10-27 读取 | 描述实际环境、命令、主要方法与基线的复核路径、结果覆盖及不可获取材料 | 复现包设计参考，具体投稿仍核对当年正式要求；文件导出和真实复现分别记录 |

匿名笔记依据涵盖已有的配方与机制组织、关键实验记录、正文故事线核对及主张证据表。它们表明工作材料中已有有价值的记录方式，某些文件是历史 Agent 整理，因此不据此推断全部内容是用户长期偏好。实际来源位置与读取摘要留在技能仓库私有审查记录，公开安装包不复制私人笔记与研究结果。

外部建议可能与个人习惯不同，例如提前写全文和最终统一整理各有适用情境。本轮沿用户明确选择，保留关键数据与 claim，最后按材料覆盖、证据强度与中心问题做取舍。阅读更多经验文章应服务一个实际缺口，不能为每条外部建议再增加一套强制流程。
