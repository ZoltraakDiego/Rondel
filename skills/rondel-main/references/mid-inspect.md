# mid.inspect：先确认产物有效，再解释结果

读取实际 run、冻结方案与设置、原始日志、检查点、预测和评价输出，确认它们确属同一次尝试。检查运行是否完整、指标与预测是否缺失或存在非有限值、样本和标签是否对齐、划分与选点是否符合计划，以及评价实现和聚合单位是否一致。不同任务使用实际语义核对，不能用文件存在代替这些检查。

工程退出、产物完整与科学可比性分别报告，定位偏差影响哪些条件与结论。无效或无法核对的尝试原样保留，说明仍有价值的信息和下一项具体检查。遇到真实实现错误先关联范围内修复或新尝试，暂不把它解释为机制失效。

purpose: run_inspection 使用 [产物核验模板](../assets/templates/run-inspection.md)，引用 run 与实际检查证据。completed 后才可按证据更新 check_status 为 valid 或 invalid，无法判断时保持 unchecked；一个检查报告存在仍不自动证明其科学判断正确。有效范围交给 mid.analyze，无效范围交回当前任务，Main 保存与计划和主问题的关系。
