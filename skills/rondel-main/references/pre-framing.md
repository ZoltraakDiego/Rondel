# pre.framing：建立检索与准备的起点

以 Init 的 `search_summary` 为检索领域起点，在 [准备总表](pre-tracking.md) 显式维护少量核心痛点及对应问题。每个核心问题关联痛点与证据，当前主问题沿用户选择进入 active；用 [焦点模板](../assets/templates/research-focus.md) 组织条件、已有路线和待验证缺口。领域摘要的修订同步画像与 Init，候选问题和技术设想保持各自来源。

先读 Init 的整体理解、当前问题和计划，恢复用户已经明确的任务、动机、约束与已有材料。将当前目标整理成一个检索锚点：研究对象、需要预测或解释什么、可用输入与监督、推理条件，以及用户最在意的行为。未知项保持开放，只追问会改变检索和准备路线的一处。

建立锚点后进入 [找论文](pre-papers.md)，用已有研究和实现逐渐修订问题。这里的产物是能够开始查证的表述，技术想法作为候选，避免尚未阅读就固定模块组合或贡献。用户修正的优先级与边界写入研究主线并保留实际来源。

记录可使用带 `purpose: preparation_brief` 的讨论，关联 `research_anchor`、当前计划与已有材料。交给 Main 时说明已经知道什么、首轮检索要区分哪些路线、用户需要参与哪项判断。研究问题的形成继续遵循 [研究引导](research-guidance.md)。
