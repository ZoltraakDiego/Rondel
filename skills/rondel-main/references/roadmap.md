# 当前能力与接续边界

Main 7、Pre 6、Mid 8、Post 7 共 28 个研究职责均可通过 rondel-main 按需使用，另有 general 处理独立问答与技能设计。各职责、输入输出和入口以 [catalog](shared/tool-catalog.yaml) 为准。当前只需安装一个完整技能目录，独立的四入口拆包仍是可选后续工程安排。

[Pre](preparation.md) 负责阅读、数据、协议、Baseline 与环境，[Mid](mid-cycle.md) 负责有限假设循环、实现、执行与归因，[Post](post-cycle.md) 负责收敛、机制、主张、图表、论文与投稿准备。阶段与模式分别管理，已有材料可直接进入相关职责，必要缺口按实际影响补足。主线和科学取舍继续由 Main 与研究者共同维护。

七个本地辅助脚本负责路由与阶段上下文、记录与历史、前期跟踪、机器汇总、笔记视图、有限清单结构检查和两份交付包导出。它们不内置训练器、远程连接、GPU 预留或投稿客户端；实际操作使用当前可用工具，按具体用户范围完成。模式、结构检查和模板不会单独授权执行，文件完整性、结果复现和科学有效分别核验。

真实任务返回问题、产物位置、来源版本、实际协议、观察与候选解释，关键选择有人的来源。阶段收束按 [阶段上下文](phase-context.md) 沉淀，按 [session 边界](session-boundaries.md) 准备新任务入口。工具关系见 [映射与回传图](main-tool-map.md)。
