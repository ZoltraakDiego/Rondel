# 从笔记取舍到两份研究包

本例为虚构情境，展示当前默认工作顺序，不包含真实研究结论。研究者在实验期间保存关键数据、条件与候选 claim，结束探索后要求：“现在把项目笔记统一整理一下，看看哪些值得写进论文，最后留下复现包和资料包。”Agent 先定位当前项目范围和实际资料，分批审阅，不把全部历史对话重新注入。

| 材料 | 当前审阅情况 | 推荐去向 | 理由与保留方式 |
|---|---|---|---|
| 主要对照与行为分析 | 原文、配置和产物已核对 | 主文候选 | 回答中心问题，主张强度随证据保存 |
| 解释主要结果所需的失败条件 | 已核对来源 | 主文或必要讨论 | 影响读者理解方法代价与适用条件 |
| 额外诊断与长推导 | 已读，与中心证据一致 | 补充候选 | 支撑中心认识，主文给入口 |
| 旁支模块与工程排错 | 已读 | 研究档案 | 保留所得经验和重开条件 |
| 版本不明确的旧指标 | 待核对 | 待核验 | 核对前不写成当前模型结果 |

Agent 给出中心发现段落与章节连接，研究者修订后再接入 post.claims、post.visualize 和 post.write。需要新增实验时，只提出会改变中心判断的一项或有限清单，完成条件和返回位置明确。已整理的笔记不会因未进入论文而被删除，资料包继续保留阅读路径、有效负结果与未解问题。

复现包的 README 说明实际代码、环境、数据和协议、命令、权重及结果入口，并区分文件核验、样例执行、主要评价和完整重训。资料包的 README 说明从哪里阅读、关键认识怎样形成、哪些选择改变了方向，以及下次从何处继续。Agent 按明确清单导出两个目录与 manifest，外部机器上的大产物保持引用，已验证范围依据真实记录。

完成交付后，Rondel 用完整段落回顾最初的困惑、研究者形成的理解、当前成果与未解项，再给出两份包的实际位置。用户选择结束时保存真实决定与归档，当前还有运行任务就按原范围交代处理方式。结尾可以说：“这一次，我们先把走过的路留在这里。愿这些证据与认识，陪你走向下一个值得追问的问题；等你带着新的疑问回来，我们再从这里继续。”

这一告别用于研究阶段或项目的实际收尾，普通状态查询和单次文件修改继续自然接续。具体规则见 [材料取舍](../skills/rondel-main/references/paper-material-selection.md)、[收尾流程](../skills/rondel-main/references/post-closeout.md) 与 [导出辅助](../skills/rondel-main/references/closeout-helper.md)。
