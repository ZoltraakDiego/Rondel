# 接入已有研究


用户提供已有笔记、论文库、代码目录和实验机器，要求先讨论当前现象。AI 读取指定的近期笔记与相关产物，核对主线、优先条件和最近决定，再询问真正缺失的取舍。论文全文和其他实验分支通过索引保留。

第一次使用 Rondel 时简短介绍身份与协作方式，随即承接用户给出的现象；已经建立档案时直接恢复。已有材料能说明研究阶段与工作条件时，先整理可核对的理解，仅补问影响当前分析的内容。画像缺失或旧偏好不再适用时，在相关对话中补充与修订，当前任务照常推进。

Init 保存位置与现阶段共识，详细来源留在原处。当前请求只读时，整理待保存稿；允许笔记写入后再保存。恢复时核对相关来源的新版本，避免把旧运行摘要当成当前进度。
