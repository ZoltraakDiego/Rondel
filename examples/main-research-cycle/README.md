# Main：从核心阅读到阶段前进

以下为虚构的行为示例，说明广读、精读与复现、用户理解和阶段评审怎样接续。它描述期望行为，没有运行研究模型或提供真实实验结果。规则见 [研究主线](../../skills/rondel-main/references/main-research-loop.md)与 [状态与推进](../../skills/rondel-main/references/main-state-and-momentum.md)。

## 核心工作不能只有 AI 摘要

假设项目已经完成主要路线的广读地图，选择了少量核心论文，并为一条优先基线留下可核对的复现记录。AI 已提供方法摘要，用户尚未阅读关键方法部分，却想继续增加模块。Main 核对出影响当前改动判断的是这篇论文的数据流与一项关键对照，推荐本轮先共同看方法图和相关实现，让用户用自己的几句话解释其设计理由。

AI 准备原文、术语与调用位置，并保留工程准备任务。用户给出自己的解释后，Main 分别记录用户已讨论的认识与仍不清楚的条件，更新核心论文卡；AI 先前写的摘要保持其来源属性。用户如果改变目标或选择换论文，则记录实际理由与相应缺口。

## 条件满足时主动建议转阶段

当首批核心工作的阅读与约定复现范围已有依据，用户能解释关键机制，协议与当前局限也已明确，Main 给出进入中期的建议。它展示这次转移所依赖的来源，并推荐一项只改变一个关键因素的验证及其对照。用户采纳后，当前任务、计划位置和阶段由实际选择接续，外围阅读仍按有界任务推进。

## 停滞后改变行动

假设连续两次约定复盘都未解决同一个归因问题，用户仍想再改超参数。Main 说明现有结果还无法区分两个解释，建议先用已有产物核对差异来源，或做一项有区分力的对照；当轮只保留这一项关键行动。用户表示时间和精力不足时，将任务缩成一次具体结果讨论，由 AI 准备相关预测与条件，明确新的检查点。

## 有证据就组织发现

当核心问题已有范围明确的证据链，剩余对照可以列为有限清单，Main 推荐进入后期收敛。用户先用自己的话表述核心发现与边界，AI 协助整理证据图与论文草稿。新的旁支想法保留在探索记录中，影响中心结论的缺口才以明确范围回到中期补充。
