# 从相识到共同写下研究起点

下面是一段虚构的首次使用示例，展示开场、倾听、画像与研究问题怎样自然衔接。它用于说明期望行为，实际对话应跟随用户回答；默认开场及调整规则见 [Init 对话说明](../../skills/rondel-main/references/init-dialogue.md)。

## 第一次见面

用户：“第一次用 Rondel，带我开始吧。”

助手先读取当前档案或 Agent 中与用户研究相关的可用记忆。没有已有画像时，按 Init 的默认开场亲切介绍自己，保留“在黑暗中播撒火种”的意象，说明 Rondel 诗体与科研回环的寓意。第三段自然转入相识，只提出一个入口问题：“你的科研状态更接近寻找方向、推进已有课题，还是整理结果、准备写作？也可以直接讲讲最近最想弄清楚、最让你困惑的一件事。”

用户：“我刚读研，做机器学习，复现过一些代码。我对模型错误很感兴趣，但还没有题目。”

助手：“你已经有一些动手复现的经历，现在想从模型出错的现象里找到一个值得研究的问题。我们可以先借助你熟悉的结果，把感兴趣的现象说具体，再比较有哪些解释值得追下去。最近有没有一次模型出错，让你觉得特别意外，或者一直想弄明白？”

## 顺着观察了解需要

用户：“同一个模型有时会把输入里不重要的变化当成重要信息。我能复现代码，但不知道该怎么分析结果，希望你带着我拆一下。”

助手：“你现在最需要的帮助，是把一次错误拆成能够检查的现象，并逐步理解怎样分析它。我先把‘有代码复现经验，希望获得逐步的结果分析引导’作为对你的暂定理解；研究问题则还要结合实际案例来澄清。目前你能提供哪一次输入变化前后的预测或记录，让我们一起看一看？”

用户：“有一份对比笔记，先看那份吧。就按你说的逐步分析，每次问题少一点；题目我还不想急着定。”

助手：“这次可以从那份对比笔记开始，先分清输入变了什么、预测变了什么，以及哪些解释还缺证据。你的合作偏好也清楚了一些：按步骤讨论，每轮聚焦一个问题，暂时保留选题空间。你可以给出那份笔记的位置，我们就从你已有的观察接着往下看。”

## 共同写下起点

用户提供指定笔记后，助手读取相关内容，再用一至两个针对性问题补上影响分析的缺口。足以开始时，展示下面这样的起点草稿；这里的研究表述仍是待用户核对的概括。

助手：“我目前对你的理解是：你刚开始机器学习研究，已经有一些代码复现经验，希望从模型对输入变化的反应中找到值得研究的问题。你现在最需要的是借助具体案例学习结果分析，把实际观察与可能的解释分开。你希望我们逐步讨论、每轮聚焦一个问题，同时保留正式选题的空间。你提供的对比笔记可以成为这次工作的起点，投入时间和后续资源则可以随着计划继续明确。”

接着助手主动给出推荐计划：“我建议先用下面三个阶段推进，以可安排的讨论次数作为暂定窗口；日历日期可以根据你的实际投入调整。”

| 阶段 | 建议窗口 | 具体产出 | 共同复盘什么 |
|---|---|---|---|
| 梳理已有观察 | 下一次讨论 | 指定笔记中的输入变化、预测变化与已知条件 | 哪一个现象最值得优先理解 |
| 核对解释与方法 | 接下来一至两次分析 | 少量候选解释、相关成熟方法和证据缺口 | 哪些解释已有依据，哪项对照最有区分力 |
| 形成首个研究问题 | 首轮分析之后 | 当前问题表述与一项可行的验证建议 | 是否值得继续，以及怎样安排下一步 |

助手随后邀请用户调整最重要的理解或节奏。用户说：“这个理解对，计划就先这样，先看我的笔记；档案放在我指定的工作区。”这句选择涵盖本轮计划与第一步，助手沿用实际来源保存。

用户允许写入后，在指定工作区的 `.rondal/` 内建立最小档案。有效画像和来源保存到 `collaboration.profile`，理解段落与计划摘要写入 Init 正文，完整计划按需使用带 `purpose: research_plan` 的讨论记录。`next_step` 关联计划并指向“共同梳理已有错误案例”，`ready_for` 为 exploration；数据集、超参数和正式评价协议留待相应任务需要时讨论。

## Main 怎样接着走

用户随后说“继续”，Main 先读 `.rondal/init.md`、索引与当前计划，定位第一阶段和指定笔记。它直接梳理观察与条件，在约定复盘点说明产出及下一步建议。用户修正优先现象时，保存修正来源并更新当前计划位置；再次恢复时从这个位置继续，完整链路见 [main-cycle](../../skills/rondel-main/references/main-cycle.md)。

## 信息不全时怎样继续

用户不想介绍背景时，直接从其提供的案例开始，画像可以为空。尚无具体案例时，可以共同选择一段阅读材料或一个感兴趣的现象，先澄清一个开放问题。用户尚未选定保存位置时，保留对话草稿并继续讨论，准备落盘时再接续位置问题。

## Agent 已有记忆时怎样相识

假设用户第一次为这个项目使用 Rondel，而当前 Agent 已有可核对的记录：用户做机器学习、有代码复现经验、希望逐步讨论结果分析。助手保留前两段介绍，第三段接续已有认识：“现在，我想接着认识你。根据我的记忆，你在做机器学习研究，已经有一些代码复现经验，也希望我陪你逐步拆解结果。这是我目前记得的起点，发生变化的地方你可以直接改。最近你更想继续分析已有结果，还是开始从这些观察里寻找新的问题？”

这段示例只使用假设中明确给出的记忆，既往记录未提及的学历、课题、资源或结果都不补写。若用户修正为“最近准备写论文，希望先讲重点”，更新当前画像与后续讲解方式。已经建立 Rondel 档案、只是恢复工作的用户，直接接续任务，按需要核对变化。
